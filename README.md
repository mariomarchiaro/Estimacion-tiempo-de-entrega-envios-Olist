# 📦 Estimación del tiempo de entrega de envíos – Olist

Proyecto de **Ciencia de Datos** orientado a la estimación del **tiempo de entrega de pedidos** en un e-commerce, utilizando el **dataset público de Olist (Brasil)**.

El objetivo es anticipar los plazos de entrega a partir de información de pedidos, clientes, vendedores y logística, con foco en **mejorar la planificación operativa y la experiencia del cliente**.

---

## 🎯 Objetivo del proyecto
Desarrollar un modelo predictivo capaz de estimar el tiempo de entrega de un pedido, permitiendo:
- Reducir incertidumbre logística
- Mejorar la comunicación con el cliente
- Apoyar la toma de decisiones operativas

---

## 📊 Dataset
- **Olist Brazilian E-Commerce Dataset**
- Incluye información de:
  - pedidos
  - clientes
  - productos
  - vendedores
  - pagos
  - reseñas
  - fechas y tiempos logísticos

---

## 🔍 Metodología
El proyecto se desarrolló siguiendo las siguientes etapas:
1. Limpieza y preparación de datos
2. Análisis exploratorio de datos (EDA)
3. Ingeniería de variables
4. Entrenamiento de modelos de machine learning
5. Evaluación y comparación de métricas

---

## 🤖 Modelos utilizados
- Regresión Lineal
- Árboles de decisión
- Modelos de ensamble (según corresponda)

Las métricas de evaluación permiten comparar el desempeño de cada modelo y seleccionar la mejor alternativa.

---

## 🛠️ Herramientas y tecnologías
- Python 
- Pandas, NumPy  
- Matplotlib / Seaborn  
- Scikit-learn  
- Jupyter Notebook  

---

## 📌 Resultados
El modelo final logra una estimación razonable del tiempo de entrega, demostrando el potencial del uso de datos históricos para optimizar procesos logísticos en e-commerce.
